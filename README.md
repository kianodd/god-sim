# خدای جهان کوچک — شبیه‌ساز زندگی و تکامل

شبیه‌سازی زنده‌ی ۱۲۰ موجود (قابل تنظیم ۵۰ تا ۵۰۰) در یک جهان ساده، با ژنتیک واقعی.

## چه می‌کند؟
- موجودات دنبال غذا می‌گردند، از گرسنگی می‌میرند، سر غذا می‌جنگند و وقتی سیر باشند و جفت پیدا کنند، بچه‌دار می‌شوند.
- **ژنتیک مندلی واقعی:** هر ژن دو آلل دارد (AA / Aa / aa)، آلل غالب و مغلوب، حامل پنهان، جدول پانت برای دو والد.
- **چندژنی:** سرعت، بینایی و جثه حاصل جمع ۳ جایگاه ژنی + اثر محیط‌اند.
- **جهش** با نرخ قابل تنظیم برای هر ژن؛ جهش‌های خنثی / مفید / مضر در لاگ ثبت می‌شوند.
- **رانش ژنتیکی، گلوگاه جمعیتی، اثر بنیان‌گذار، جریان ژنی** (ورود مهاجر)، **افسردگی هم‌خونی** (ضریب F در کارت موجود)، **انتخاب طبیعی و جنسی** (ترجیح ماده‌ها قابل تنظیم)، **تعادل هاردی–واینبرگ** با p و q و انحراف از تعادل، **اپیستازی** (ژن «پوشش تیره» رنگ پوشش را می‌پوشاند).
- **آزمایشگاه ژنتیک:** برای هر ژن غالب/مغلوب بودن، نرخ جهش و شدت اثر را عوض کن؛ دکمه‌ی بازنشانی به حالت علمی استاندارد.
- **قدرت‌های خدا:** باران غذا، صاعقه، شهاب، طاعون، برکت، خشکسالی، گلوگاه، مهاجر.
- **آمار زنده:** نمودار جمعیت، فرکانس ویژگی‌ها، فرکانس آلل‌ها (p و q)، تبارها، علت مرگ‌ها و دفتر رویدادها.
- **راهنمای ژنتیک** داخل اپ (تب 📖 راهنما): هر قانون با یک جمله‌ی ساده و یک مثال از همین سیمولیشن.
- ذخیره/بارگذاری در مرورگر (شامل همه‌ی قوانین ژنتیک)، خروجی JSON آمار و رویدادها.
- کاملاً ریسپانسیو و تاچ‌فرندلی؛ روی موبایل پنل به‌شکل Bottom Sheet با تب‌هاست.

## اجرا
فقط `index.html` را باز کن — بدون بیلد و بدون وابستگی (به‌جز فونت وزیرمتن از گوگل، با فونت سیستمی جایگزین).
